About Me

Building Clean, Responsive Web Apps with Strong Algorithmic Fundamentals

Hi! I'm Abhinay, a Computer Science Engineering student at SRM University AP, an AFE-FFE Scholar, and an AWS Emerging Talent Member based in Guntur, Andhra Pradesh.

I focus on building clean, accessible, and responsive user interfaces using semantic HTML5, modern CSS3 (Flexbox & Grid), and vanilla JavaScript. Rather than relying on heavy external frameworks, I prioritize strong core web fundamentals — creating intuitive layouts that work smoothly across mobile, tablet, and desktop viewports, and writing clean DOM logic for interactive features like form validation and dynamic filters.

Alongside frontend development, I actively solve algorithmic challenges using Data Structures & Algorithms in C++, giving me a disciplined approach to code efficiency, problem decomposition, and time-space optimization.
